# GitHub Collaboration Assignment

## Project Overview
This project demonstrates collaborative software development using GitHub.

## Objectives
- Create and manage feature branches.
- Develop changes without directly modifying main.
- Submit Pull Requests.
- Review code and provide feedback.
- Approve and merge changes.

## Feature
This repository includes a student profile feature.

## Workflow
Create Branch → Develop → Commit → Push → Pull Request → Review → Merge
